SHOPIFY

Features
Screen 1: Product Listing
Fetches products from a public/mock API.

Displays image, name, price, and short description.

Shows loading indicator while fetching data.

Handles API errors.

Navigates to detail screen on product tap.

Screen 2: Product Detail
Displays full product info: image, name, price, and description.

Buttons to add product to cart and wishlist.

Shows confirmation messages on actions.

Screen 3: Cart
Lists products added to the cart.

Supports quantity increase/decrease and item removal.

Shows total price.

Screen 4: Wishlist
Displays products added to wishlist.

Allows moving items to cart or removing them.
